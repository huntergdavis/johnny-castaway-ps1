The Binary Library

The heavy regression corpus was useful, expensive, and ultimately replaced by scene-by-scene pixel validation.

~1 min read · 131 words

The binary library was the branch’s brute-force regression archive: historical PS1 builds, CD images, manifests, and index files used to bisect visual behavior while the rendering method was still unsettled. It made sense when the project needed to compare whole historical states and did not yet have a stable foreground playback path.

That era is over. The live workflow is scene-by-scene validation against the FG2/FGP3 foreground methodology, capped at v0.9.2-ps1 with all 63 of 63 scenes signed off and a separate performance ledger tracking target-speed convergence. The full binary payload is not intended to live in the repo; the searchable archaeology records are enough to recover the story.
