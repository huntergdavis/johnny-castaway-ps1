Johnny Castaway, the character, the original screensaver, and all original Sierra art / audio assets are © Sierra On-Line and are not licensed under GPL.

This project ships only the code that drives the port. End users running the released .bin/.cue are playing baked playback packs — small binary files that record what the original engine drew, in a form the PS1 can render. The host build, used during development, requires the original Sierra data files (RESOURCE.MAP, RESOURCE.001) which the user must supply themselves.
