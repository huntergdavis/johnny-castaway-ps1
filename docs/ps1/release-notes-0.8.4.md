# v0.8.4-ps1 Release Notes

**Date:** 2026-05-08
**Tag:** `v0.8.4-ps1`
**Theme:** Custom chapter-select thumbnails for all 63 scenes

`v0.8.4-ps1` is a content-and-UX point release after `v0.8.3-ps1`. The
in-game Scene Explorer (the chapter-select grid reachable from the pause
menu) ships a custom on-PS1-captured thumbnail for every one of the 63
scenes, and the scene-page metadata across the website is reconciled
against what the discs actually play. No perf code changed; the matrix
mean is unchanged.

## Headline

- **All 63 chapter-select thumbnails are custom captures.** Each scene's
  pack was booted under DuckStation with a per-scene ISO, played to a
  representative frame, captured at native resolution, and encoded as a
  320×240 RGB555 little-endian SCR at `jc_resources/extracted/scr/SX*.SCR`.
  No scene falls back to the auto-generated frame any more.
- **Scene titles, descriptions, and bodies were reconciled with the
  on-PS1 packs.** Many of the prior caption-mapping audit guesses turned
  out wrong once the scenes were watched on hardware. Per-scene commits
  lift the "What this scene probably is (Guess.)" hedging on every page
  it appeared on, in lockstep with the new thumbnail.
- **The earlier audit got several scenes mismapped.** "He catches a boot"
  belongs to MARY 2, not FISHING 2; "He catches a crab. It snaps his
  nose" is a different fishing gag, not FISHING 3 (which on PS1 is the
  octopus-steals-fish beat); the coconut-plane-hit gag is VISITOR 5, not
  VISITOR 4; and "jogs around the island" is WALKSTUF 3, not WALKSTUF 1.
  Each correction is recorded in its scene's commit and ledger row.
- **One missing-manifest bug caught and fixed.** `config/ps1/cd_layout.xml`
  only listed 42 of the 63 thumbnail SCRs; the 21 newly-created ones (the
  BUILDING 2–7, MISCGAG 1–2, STAND 1–5, SUZY 1–2, VISITOR 1+3–7 cluster)
  were on disk but never made it onto the CD because the manifest didn't
  reference them, and `grLoadSceneExplorerThumbnail` saw "file not on
  disc" for those rows. Manifest now lists all 63 and every Scene
  Explorer slot loads.
- **`scripts/apply-scene-correction.py` is the new in-loop tool.** Single
  command updates all five sources of truth per scene (per-page
  index.md title + description + body, scenes.yml notes, scene-status.md
  Notes column, optional thumbnail SCR encoding, local progress tracker)
  in one pass. Idempotent failure mode: re-running on an already-corrected
  scene fails noisily on the exact-string Edit so a re-run can't silently
  clobber a prior fix.

## Reconciled metadata surfaces

Five sources of truth per scene were updated in lockstep:

1. **Per-scene page** at `site/scenes/<slug>/index.md` — frontmatter
   `title:`, frontmatter `description:`, and the "What this scene is"
   body section (replacing the older "What this scene probably is
   (Guess.)" + caption-mapping confidence framing).
2. **Scenes ledger data** at `site/_data/scenes.yml` — `notes:` field
   prepended with a one-line canonical lead so the existing engineering
   detail survives.
3. **Scene status table** at `docs/ps1/scene-status.md` — Notes column
   prepended with the same canonical lead.
4. **Scene Explorer thumbnail** at
   `jc_resources/extracted/scr/SX<abbrev><tag>.SCR` — converted from the
   captured PNG via the existing `png_to_thumbnail_scr` helper.
5. **Scene Explorer header** at `src/pause_menu/scene_explorer_data.h` —
   regenerated by `scripts/build-scene-explorer-data.py` so the
   in-game menu titles match the corrected scene-page titles.

## Verification

- Visual check on DuckStation after the rebuild: every Scene Explorer
  grid slot shows a custom thumbnail and the menu title matches what the
  scene actually plays.
- The 21-thumbnail manifest gap surfaced as a bug report ("STAND 2–5,
  BUILDING 2–7 don't load") during that visual check; the fix was
  verified with a clean `comm` between the manifest and the filesystem.
- No perf code or pack content changed. The 120 timing-bearing rows on
  `/perf/` average the same `+0.5576%` public over target / `99.4669%`
  public target speed as v0.8.3-ps1.
- Scene validation scope is unchanged: 63 / 63 remain signed off.
