Sprites, sounds, packs

Resource catalog

508 source and generated runtime assets indexed for the site.

The code is only half the port. The other half is the pile of tiny artifacts: Sierra bitmaps, ADS scripts, TTM animations, VAG samples, PSB sprite banks, and the generated FG2 packs the PS1 actually replays. This page is the map.

It intentionally links to source files rather than copying every binary into the website. The GitHub tree remains the canonical archive; this page makes it readable.

Pair this with the source library for Markdown documentation, the scene ledger for runtime status, and the Curious Hacker’s Guide for the practical porting path.

Generated foreground packs

The runtime artifacts the PS1 actually replays. Each scene contributes a high-tide pack and a low-tide pack — <SCENE>.FG2 and <SCENE>LOW.FG2 (or its prefix-truncated equivalent for scene names long enough that the 8.3 disc filename rule cuts in, e.g. ACTV12L.FG2). The FG2 format carries its own palette, frame-timing table, base-frame full render, and per-frame diff spans; most scenes have moved to the denser FGP3 successor internally while keeping the .FG2 filename. Per-pack runtime timing lives on the performance battle card.
