Every Markdown file gets a page

Source library

325 source documents, wrapped for the website instead of buried in the repository tree.

This is the shelf I wanted when the project stopped being a codebase and became an archive. Every Markdown document outside the website tree gets a public page: active docs, generated scene specs, archaeology notes, old plans, status reports, and things that are half fossil, half runbook.

The pages are generated. The source files remain canonical. The value here is navigation: each page names the source path, extracts the outline, gives a short read of why that file matters, and links back to GitHub.

Use this with the resource catalog for binary assets, the regtest case shelf for host references, and the Curious Hacker’s Guide for a guided learning path through the machinery.
