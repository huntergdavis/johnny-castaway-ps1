{%- comment -%} aria-current="page" marks the current page in the nav so screen readers announce "current page" on the active link. Matches the contains-based pattern in _includes/header.html, with two careful cases: - Archaeology vs. Regtest cases. The Regtest case shelf lives at /archaeology/regtest-references/cases/, so a naive `contains '/archaeology/'` test would mark BOTH links current on a case-shelf page. The cases-prefix is tested first (longest match wins) and Archaeology only fires when the page is NOT a case-shelf page. - Glossary. The link goes to /docs/glossary/ specifically; using `contains` would fire on any /docs/* page and the header's Docs link already covers the section. Exact match is the right precision here. {%- endcomment -%} {%- assign nav_cases_pfx = page.url | slice: 0, 38 -%} {%- assign nav_is_cases = false -%} {%- if nav_cases_pfx == '/archaeology/regtest-references/cases/' -%}{%- assign nav_is_cases = true -%}{%- endif -%}
