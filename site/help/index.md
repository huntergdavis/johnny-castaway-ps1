desk for the PS1 port: what to press, what each menu screen does, and where
the debug power tools live once you want to poke at the island instead of
just watching it.

The menu screenshots are intentionally generated by automation. A guide
page that cannot regenerate is a failed test, and a failed test is a gift:
it tells us the controller path, the menu state machine, or the screenshot
pipeline needs attention before a release goes out.
