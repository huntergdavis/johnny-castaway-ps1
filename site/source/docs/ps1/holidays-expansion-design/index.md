## Why this file matters

**Active PS1 reference.** This is active engineering documentation for the PS1 port. It is close enough to the code that stale claims here become real bugs.

Historical design ideation for expanding Johnny Castaway PS1 from 4 holidays to 35 well-distributed, US-centric celebrations. The current art deliverable does not implement these as full scenes; it reduces each new holiday to one small transparent 32x32 emblem sprite. See holidays-pipeline.md and holidays-style-guide.md for the active art contract.
