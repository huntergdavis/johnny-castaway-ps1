## Why this file matters

**Active PS1 reference.** This is active engineering documentation for the PS1 port. It is close enough to the code that stale claims here become real bugs.

v0.8.7-ps1 is a stability and operability point release after v0.8.6-ps1. It does not promote a new performance matrix row. Instead, it hardens the machinery we use to prove what the PS1 runtime actually booted, fixes a Suzy backdrop state leak, and makes Scene Explorer preview loading independent of a large paused-menu heap allocation.
